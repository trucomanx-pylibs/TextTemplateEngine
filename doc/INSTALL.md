# text_template_engine

Lightweight engine for rendering text templates into output files.


## Install from PYPI

The homepage in pipy is https://pypi.org/project/text_template_engine/

```bash
pip install --upgrade text_template_engine
```

## Install from source
Installing `text-template-engine-info` program

```bash
git clone https://github.com/trucomanx-pylibs/TextTemplateEngine.git
cd TextTemplateEngine
pip install -r requirements.txt
cd src
python -m build
pip install dist/text_template_engine-*.tar.gz
```

## Uninstall

```bash
pip uninstall text_template_engine
```

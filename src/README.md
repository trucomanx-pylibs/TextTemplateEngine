# text_template_engine

Lightweight engine for rendering text templates into output files.

## 1. Installing

To install the package from [PyPI](https://pypi.org/project/text_template_engine/), follow the instructions below:


```bash
pip install --upgrade text_template_engine
```

Execute `which text-template-engine-info` to see where it was installed, probably in `/home/USERNAME/.local/bin/text-template-engine-info`.

## 2. Examples

To see some examples, visit the [example](https://github.com/trucomanx-pylibs/TextTemplateEngine/blob/main/example) directory.

## 3. More information

To see the package information:

```bash
text-template-engine-info
```

For more information, visit the [doc](https://github.com/trucomanx-pylibs/TextTemplateEngine/blob/main/doc) directory.
